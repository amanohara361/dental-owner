## 2. 公庫の創業計画書（記入例）歯科診療所

**事実**（公庫「創業計画書（記入例）（歯科診療所）」令和7年4月1日版、PDF原本を取得。確認日: 2026-11-24。数値は**記入例の架空の数字**）

- 公庫は、創業計画書の書式と業種別の記入例を公開しており、歯科診療所の例がある。書式は公庫のものを使わず、**自分で作った計画書を出してもよい**と記載されている
- 記入例の**必要な資金**:

| 区分 | 内訳 | 金額 |
| --- | --- | --- |
| 設備資金 | 診療所の内外装工事（設備工事含む） | 500万円 |
| | 診療設備（医療機器・歯科用ユニット等） | 1,000万円 |
| | 什器・備品類 | 100万円 |
| | 保証金 | 100万円 |
| 運転資金 | 商品仕入、経費支払資金など | 345万円 |
| **合計** | | **2,045万円** |

- 記入例の**調達の方法**: 自己資金745万円、公庫の借入1,000万円、他の金融機関等の借入300万円（合計2,045万円）
- 記入例の**事業の見通し（月平均）**:
  - 創業当初: 売上高212万円（保険診療の平均単価6,000円×15人×23日＝207万円、自由診療が月5万円）、売上原価（原価率20%）42万円、経費128万円（人件費60万円、家賃15万円、支払利息3万円、その他50万円）、**利益42万円**
  - 創業1年後（軌道に乗った後）: 売上高276万円（創業当初の1.3倍）、経費158万円、**利益63万円**
- 利益の欄の注記: **所得税などの税金や借入金の返済元金は、この利益から支払われる**。人件費の例は、従業員2人（各25万円）とパート1人（10万円）で、院長本人の報酬は経費に含まれていない
- 記入例が前提とする競合: 最寄り駅の周辺に歯科クリニックが4か所、自由診療を提供する医院が2か所

**示唆**

- **公庫は、設備資金と運転資金を分けて、見積書の根拠を添えて書かせる形式を示している。** 運転資金345万円は、記入例では月の経費（原価42万円＋経費128万円＝170万円）のおよそ2か月分にあたる。
  11/17に確認した「診療報酬の入金は診療月の約2か月後」と対応する組み立てだが、**記入例が何か月分を根拠にしたかの説明はない**ため、運転資金の目安として断定しない
- 記入例の利益（月42万円）は、**税金と借入の返済元金を払う前の数字**。公庫1,000万円と他の金融機関300万円の返済額（返済期間・利率）は記入例に書かれておらず、返済後に残る金額は計算できない。自分の計画では、返済額を入れた収支を作る必要がある
- 記入例は、公庫の説明のための例である。**実際の開業費用は、診療所の規模・物件・設備の構成で大きく変わる**ため、この金額を相場として使わない

出典: [公庫 創業計画書（記入例）（歯科診療所）（PDF）](https://www.jfc.go.jp/n/service/pdf/kaigyourei08_250401j.pdf) /
[公庫 各種書式ダウンロード（国民生活事業）](https://www.jfc.go.jp/n/service/dl_kokumin.html)
（確認日: 2026-11-24。PDF原本を取得。表の構造が複雑なため、項目と金額の対応は読み取りによる）
