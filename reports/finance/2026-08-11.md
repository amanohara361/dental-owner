## 1. 【訂正】日本政策金融公庫の利率 — 一次情報で確定

**事実**

日本政策金融公庫の公式利率表（**令和8年8月3日現在**）より。国民生活事業。

**無担保で融資を利用する場合（税務申告を2期終えている方）**

| 区分 | 年利 |
| --- | --- |
| 基準利率 | 3.60〜5.30% |
| 特別利率A | 3.20〜4.90% |
| 特別利率B | 2.95〜4.65% |
| 特別利率C | 2.70〜4.40% |

**無担保・税務申告を2期終えていない方の基準利率: 3.55〜5.25%**

**有担保で融資を利用する場合**

| 区分 | 年利 |
| --- | --- |
| 基準利率 | 2.60〜4.90% |
| 特別利率A | 2.20〜4.50% |
| 特別利率B | 2.05〜4.25% |
| 特別利率C | 2.00〜4.00% |

公式サイトに「利率は、金融情勢によって変動しますので、お借入金利（固定）は、
記載されている利率とは異なる場合があります」との注記がある。

**示唆**

- **前回（8/7）レポートの「基準利率 3.35〜4.75%」は、一次情報と一致しない。撤回する。**
  二次情報（融資支援業者のサイト）を根拠にしていたことが原因。
  同レポートの該当箇所は本レポートで訂正する
- **有担保と無担保で基準利率が1%前後違う**（無担保3.60〜5.30% / 有担保2.60〜4.90%）。
  8,000万円規模では担保提供の有無が総返済額に大きく効く。
  ただし担保に何を差し入れるかは別のリスク判断であり、利率差だけで決めない
- 利率は**幅で示されている**。下限が適用される前提で資金計画を組まない

出典: [日本政策金融公庫 金利情報（国民生活事業）](https://www.jfc.go.jp/n/rate/index.html) /
[金利一覧](https://www.jfc.go.jp/n/rate/)（確認日: 2026-08-11。表示時点: 令和8年8月3日現在）

## 2. 【訂正】創業支援貸付利率特例制度 — 適用条件の理解を修正

**事実**

公庫の制度ページ原文より。

- 対象: **「新たに事業を始める方または事業開始後税務申告を2期終えていない方」**
- 引き下げ幅
  - **「各種融資制度に定める利率 −0.65%」**
  - **雇用の拡大を図る場合「各種融資制度に定める利率 −0.9%」**
- 「上記以外の融資条件は、各種融資制度に定める条件が適用されます」

**示唆**

- **前回レポートの「従業員を雇用しない場合▲0.65% / 雇用する場合▲0.9%」という
  書き方は正確でない。** 原文は「雇用の拡大を図る場合」に▲0.9%であり、
  単に従業員がいることではなく**雇用拡大の計画**が条件と読める
  （公庫サイトには「創業特例・雇用拡大計画書」の様式がある）
- また対象が「**税務申告を2期終えていない方**」に限られる。
  開業後3年目以降の追加融資では、この特例は使えない読みになる
- 基準利率3.60%に▲0.9%を当てても2.70%であり、前回書いた「適用後2.70〜4.10%」の
  下限はたまたま近いが、**上限は5.30−0.9=4.40%**で前回の数字と合わない

**所管の窓口で要確認**: 雇用拡大の要件、計画書の記載内容、
自院が特例の対象に当たるかは、公庫の支店で確認すること。
本レポートは制度の存在と引き下げ幅を確認したにとどまり、適用の可否は判断していない。

出典: [日本政策金融公庫 創業支援貸付利率特例制度](https://www.jfc.go.jp/n/finance/search/sogyo_tokurei_m.html)（確認日: 2026-08-11）

## 3. 新規開業・スタートアップ支援資金 — 制度条件を一次情報で確認

**事実**

- ご利用いただける方: **「新たに事業を始める方または事業開始後おおむね7年以内の方」**
- 資金の使いみち: 事業開始のため、または事業開始後に必要とする**設備資金および運転資金**
- **融資限度額: 7,200万円**
- 返済期間
  - **設備資金: 20年以内（うち据置期間5年以内）**
  - **運転資金: 10年以内（うち据置期間5年以内）**
- 利率: **基準利率が原則**。要件を満たす場合に特別利率A・B・Cが適用される
  （女性・若年層・シニア層、認定創業支援等事業の受講者、
  ベンチャーキャピタルからの出資者、技術・ノウハウに新規性がある方など）
- 担保・保証人: 「お客さまのご希望を伺いながらご相談させていただきます」

**示唆**

- **限度額7,200万円は、前回押さえた開業総額（テナント8,000万〜1億円）に届かない。**
  公庫単独では不足する前提で、自己資金・民間金融機関・リースの組み合わせを設計する
- **据置期間5年以内**は資金繰り上の効きが大きい。保険診療の入金が約2ヶ月遅れる
  歯科では、開院直後の元金据置をどう置くかで初年度の資金繰りが変わる
- 特別利率の該当要件に**女性・若年層・シニア層**がある。該当すれば基準利率から
  0.4%前後下がる（無担保: 基準3.60〜5.30% → 特別A 3.20〜4.90%）。
  創業支援貸付利率特例制度との併用可否は**未確認**

出典: [日本政策金融公庫 新規開業・スタートアップ支援資金](https://www.jfc.go.jp/n/finance/search/01_sinkikaigyou_m.html)（確認日: 2026-08-11）

## 4. 令和8年度改定 — 歯科初再診料の実点数（一次情報）

**事実**

厚生労働省「令和8年度診療報酬改定の概要【歯科】」（令和8年3月5日版）より。

| 項目 | 現行 | 改定後 |
| --- | --- | --- |
| 歯科初診料 | 267点 | **272点** |
| 歯科再診料 | 58点 | **59点** |
| 地域歯科診療支援病院歯科初診料 | 291点 | 296点 |
| 地域歯科診療支援病院歯科再診料 | 75点 | 76点 |

新設された**歯科外来物価対応料**

| | R8年 | R9年 |
| --- | --- | --- |
| イ 初診時 | 3点 | 6点 |
| ロ 再診時等 | 1点 | 2点 |

- 診療報酬本体 +3.09% は**令和8年6月施行**（薬価▲0.86%は令和8年4月施行）
- 歯科診療所への配分: 物価対応分 +0.02%、経営環境悪化を踏まえた緊急対応分 +0.01%
- 各科改定率: 歯科 +0.31%

**示唆**

- 初診1件あたり **+5点（50円）＋物価対応料3点（30円）= 80円**。
  再診は **+1点＋1点 = 20円**。1日40人・再診8割で試算すると**日額2,000円弱**。
  年間250日で50万円程度の増収イメージにとどまる
- **令和9年に物価対応料が倍増する**（初診3→6点、再診1→2点）ため、
  収支計画は R8年度と R9年度を分けて置く
- 前回レポートの「本体+3.09%を収益改善と読んではいけない」という結論は、
  実点数で裏付けられた

出典: [厚生労働省 令和8年度診療報酬改定の概要【歯科】（PDF）](https://www.mhlw.go.jp/content/12400000/001671913.pdf)（確認日: 2026-08-11）
