# 法令・手続き・人事レポート 2026-10-26

## サマリ

**外来医師過多区域の事前届出が歯科診療所に適用されるかを、国のガイドラインと東京都の案内で確認した。**
歯科を対象とする・除くという明記は新制度の記載には見つからなかったが、区域の基準は**診療所の医師数**に基づき、
東京都の従来の外来医療計画の手続きは**歯科診療所を除く**と明記されている。国が示した候補区域は全国9か所（東京都内5圏域を含む）。
東京都は区域をまだ指定していない（2026年4月時点）。

## 1. 外来医師過多区域とは — 国の基準と候補区域（令和8年3月27日）

**事実**（厚生労働省医政局地域医療計画課の事務連絡、原文を取得して確認）

- 根拠は改正医療法（令和7年法律第87号）第30条の18の6。国が示す**候補区域**の基準は、
  「外来医師偏在指標が全国平均値＋標準偏差の1.5倍以上」かつ「可住地面積あたり診療所数が上位10%以上」
- 候補区域は**9つの二次医療圏**:

| 都道府県 | 二次医療圏 | 該当市区町村 |
| --- | --- | --- |
| 東京都 | 区中央部 | 千代田区、中央区、港区、文京区、台東区 |
| 東京都 | 区西部 | 新宿区、中野区、杉並区 |
| 東京都 | 区西南部 | 目黒区、世田谷区、渋谷区 |
| 東京都 | 区南部 | 品川区、大田区 |
| 東京都 | 区西北部 | 豊島区、北区、板橋区、練馬区 |
| 京都府 | 京都・乙訓 | 京都市、向日市、長岡京市、大山崎町 |
| 大阪府 | 大阪市 | 大阪市 |
| 福岡県 | 福岡・糸島 | 福岡市、糸島市 |
| 兵庫県 | 神戸 | 神戸市 |

- 実際の区域は**都道府県が候補の中から指定**する。候補の中の特定の市区町村・地区に絞って指定することもありうる

出典: [厚生労働省 外来医師過多区域に係る候補区域の公表について（事務連絡、令和8年3月27日）](https://www.mhlw.go.jp/content/10800000/001681549.pdf)
（確認日: 2026-10-26。PDF原本を取得し確認）

**示唆**

- **これまで週次で調べた東京23区のうち、北部（豊島・北・板橋）、西部（練馬・杉並・中野）、南部（大田・品川・世田谷）は
  候補区域に含まれる。** 神奈川・埼玉・千葉の各エリア（横浜・川崎・さいたま・多摩・千葉県北西部・千葉市・川口・相模原）は候補になっていない
- ただし**この制度が歯科診療所に及ぶかが前提**（次章）

## 2. 歯科診療所への適用 — 明記なし、ただし基準は医師数ベース

**事実**

- 厚生労働省の「外来医療に係る医療提供体制の確保に関するガイドライン（第8次〈後期〉、令和8年5月）」では、
  外来医師偏在指標を「**外来医療のサービスの提供主体は医師であることから**」医師数に基づく指標とし、
  人口10万人対**診療所医師数**を用いると定めている。大半の診療所は1人の医師で運営されるため診療所数とほぼ1対1に近い、とも書かれている。
  この基準で「歯科」を明示的に含める・除く記載は、ガイドラインの本文では確認できなかった
  （「歯科」の語が出るのは、事前届出の記載事項〈従業者の定員: 医師、歯科医師、薬剤師、看護師ほか〉のみ）
- 東京都保健医療局の外来医療計画のページ（令和8年4月24日更新）では、従来の外来医療計画に関連する手続き
  （診療所の新規開設時の「地域医療への協力意向の確認」、CT・MRI等の共同利用計画）について、
  「診療所（**歯科診療所を除く**）」と明記されている。一方、新設の**事前届出**の案内には、歯科についての記載がない
- 東京都は令和8年4月時点で、**外来医師過多区域をまだ指定していない**。事前届出が必要になるのは、都が区域の指定と
  地域外来医療等を公表してから**6か月後に開設する診療所**。例: 令和8年10月1日に指定した場合、令和9年4月1日以降の開設が対象
  （指定にあたり周知期間を設けることも検討中）

**示唆**

- **歯科診療所が事前届出の対象かは、公開資料からは確定できない。** 区域の基準が医師数に基づき、都の従来の関連手続きが歯科を除いていることから、
  歯科は対象外とみる余地があるが、**「無床診療所」という新制度の文言に歯科診療所が含まれるかは、法令・通知の解釈による**。
  断定せず、開業予定地の都道府県（医療政策課）で確認する
- 東京23区で開業を検討する場合は、**都が区域を指定する時期と、周知期間**を継続して確認する。
  指定が出る前でも、6か月前の届出が必要かもしれない時期の開業なら、早めの問い合わせが無難

出典: [厚生労働省 外来医療に係る医療提供体制の確保に関するガイドライン（第8次〈後期〉、令和8年5月）](https://www.mhlw.go.jp/content/001718582.pdf) /
[東京都保健医療局 東京都外来医療計画](https://www.hokeniryo.metro.tokyo.lg.jp/iryo/iryo_hoken/kanren/gairaikeikaku)（更新日2026-04-24）
（確認日: 2026-10-26。いずれも原文を取得して確認）
