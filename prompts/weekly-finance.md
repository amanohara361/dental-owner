# 毎週火曜8時 — 財務情報の収集

`CLAUDE.md` の役割定義に従って実行する。

## 手順

1. `reports/finance/` の直近3ファイルを読み、既に押さえた論点と「未確認」項目を把握する。
2. 以下の観点で、前回（1週間前）から新しく出た情報を調べる（WebSearch / WebFetch を使う）。
   - 開業資金の相場と内訳（内装、ユニット、CT、レセコン、運転資金）
   - 融資: 日本政策金融公庫の制度・金利、信用保証協会、医師会系の斡旋
   - 機器のリース vs 購入、償却
   - 診療報酬改定の動向と収益インパクト
   - 補助金・助成金の公募状況と締切
   - 損益分岐点、必要患者数、人件費率の目安
3. 前回から**変わった点**を優先する。変化がなければ「変化なし」と明記し、
   未確認項目を1つ潰す。
4. `reports/finance/YYYY-MM-DD.md` に書き出す（形式は `CLAUDE.md` の「レポートの形式」）。
5. コミットして `claude/dental-startup-advisor-ctrpar` に push する。
6. チャットへの報告は100字以下。サマリ1行＋次のステップ1つ。

## 注意

- 金額は必ず出典と時点を添える。相場を丸めて断言しない。
- 個別の税務・融資審査の可否は判断しない。「税理士／公庫窓口に確認」と書く。
- 相談者の財務数値を検索クエリや外部送信に含めない。
