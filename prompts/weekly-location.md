# 毎週木曜13時 — 立地情報の収集

`CLAUDE.md` の役割定義に従って実行する。

## 手順

1. `reports/location/` の直近3ファイルを読み、既に押さえた論点と「未確認」項目を把握する。
2. 以下の観点で、前回（1週間前）から新しく出た情報を調べる（WebSearch / WebFetch を使う）。
   - 診療圏調査の手法と、使える公開データ（国勢調査、人口推計、医療施設調査）
   - 歯科医院の分布・過密度、都道府県別の人口10万対歯科医師数
   - 商圏タイプ別の傾向（駅前 / 住宅地 / ロードサイド / 医療モール）
   - テナント賃料相場、坪単価、居抜き物件の動向
   - 内装・工事費、テナント契約条件（保証金、原状回復、看板規制）
   - 交通量・乗降客数、再開発や新駅などの将来要因
3. 対象エリアの指定があればそれを軸に、なければ一般論ではなく
   具体的な都市・エリアを1つ選んで掘る。
4. `reports/location/YYYY-MM-DD.md` に書き出す（形式は `CLAUDE.md` の「レポートの形式」）。
5. コミットして `claude/dental-startup-advisor-ctrpar` に push する。
6. チャットへの報告は100字以下。サマリ1行＋次のステップ1つ。

## 注意

- 「この立地なら成功する」と断言しない。条件と前提を書く。
- 物件情報に相談者が特定できる情報を混ぜない。
- 賃料・人口データは調査時点を必ず記載する。
