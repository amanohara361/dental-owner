# 歯科開業前チェックリスト

最終更新: 2026-08-06

財務・立地以外に、開業前に潰しておくべき論点。**法令・許認可 / 人事・労務 /
保険診療の実務 / リスク・その他**の4分野。

数字・期限・要件は制度改定で動く。実際の手続き前に、必ず所管の窓口
（保健所・地方厚生局・労基署・税務署）で最新の要件を確認すること。
本チェックリストは論点の抜け漏れ防止が目的で、法的助言ではない。

凡例: `[ ]` 未着手 / `[~]` 進行中 / `[x]` 完了 / **未確認** = 情報が取れていない項目

## 1. 法令・許認可

### 1-1. 期限のある届出

もっとも事故が起きやすい領域。**保険医療機関の指定**が全体スケジュールの
制約条件になる。

| # | 手続き | 提出先 | 期限の目安 | 状態 |
| --- | --- | --- | --- | --- |
| 1 | 診療所開設届 | 保健所 | 開設後10日以内 | `[ ]` |
| 2 | 保険医療機関指定申請 | 地方厚生局（都道府県事務所） | 月ごとの締切あり／指定日は原則翌月1日 | `[ ]` |
| 3 | エックス線装置備付届 | 保健所 | 備付後10日以内 | `[ ]` |
| 4 | 防火対象物使用開始届 | 消防署 | 使用開始の7日前 | `[ ]` |
| 5 | 個人事業の開業届 | 税務署 | 開業後1ヶ月以内 | `[ ]` |
| 6 | 青色申告承認申請 | 税務署 | 開業後2ヶ月以内 | `[ ]` |
| 7 | 給与支払事務所等の開設届 | 税務署 | 開設後1ヶ月以内 | `[ ]` |
| 8 | 麻薬施用者免許（該当時） | 都道府県 | 使用開始前 | `[ ]` |

**最重要**: 2の保険指定は「内装完成・保健所への開設届済み」が前提。
締切を1日外すと、開院してもその月は**自費診療のみ**になる。
逆算スケジュールの起点をここに置く。

- `[ ]` 管轄の地方厚生局事務所の**申請締切日**を確認し、カレンダーに入れる
- `[ ]` 保健所の**事前相談**（図面段階）を予約する。設計変更を防ぐため内装着工前に

### 1-2. 構造設備・安全管理

- `[ ]` 医療法上の構造設備基準（診療室・待合室・消毒設備・エックス線室の遮蔽）
- `[ ]` エックス線室の遮蔽計算、線量測定、放射線防護
- `[ ]` バリアフリー、消防設備（誘導灯・消火器）、避難経路
- `[ ]` 感染性廃棄物の処理委託契約、マニフェスト運用
- `[ ]` 医薬品・材料の管理、滅菌工程の記録

### 1-3. 広告・情報管理

- `[ ]` 医療広告ガイドライン準拠（HP、看板、チラシ、内覧会の表示）

  - 自費診療は費用・リスク・副作用の併記が要件になる
- `[ ]` 個人情報保護法／医療情報システムの安全管理ガイドラインへの対応

### 1-4. 開設形態

- `[ ]` 個人開業 / 医療法人化の判断と、法人化するタイミングの目安

## 2. 人事・労務

### 2-1. 採用

- `[ ]` 必要人員の設計（歯科衛生士・歯科助手・受付・技工の外注可否）
- `[ ]` 地域別の給与相場（歯科衛生士は採用難易度が高く、賃金が上振れしやすい）
- `[ ]` 採用チャネルの選定と費用（求人媒体・人材紹介・専門学校・リファラル）
- `[ ]` **採用は開院の2〜3ヶ月前に開始**。入職後の研修・オペ練習の期間を確保
- `[ ]` 開院前トレーニング（診療の流れ、レセコン操作、電話・受付応対）

### 2-2. 労務の整備

- `[ ]` 雇用契約書・労働条件通知書のひな形
- `[ ]` 就業規則（常時10人以上で作成・届出義務）
- `[ ]` 36協定、勤怠管理の方法
- `[ ]` 社会保険・労働保険の適用関係の確認（開設形態と常時使用者数で変わる）
- `[ ]` 雇用時・定期の健康診断、B型肝炎ワクチン
- `[ ]` 針刺し事故・感染曝露時の対応手順を文書化
- `[ ]` 給与計算の体制（自前 / 社労士 / ソフト）

### 2-3. 外部の専門家

- `[ ]` 税理士（医科歯科に強いか、記帳・決算・保険診療の理解）
- `[ ]` 社会保険労務士（就業規則・助成金）
- `[ ]` 歯科医師会の入会可否 — 会費と、休日当番・研修・紹介の実利を比較

## 3. 保険診療の実務

見落とすと収支計画がそのままずれる領域。

### 3-1. 施設基準の届出

歯科初診料の注1に関する届出（いわゆる**歯初診**）、外来環境体制、
かかりつけ歯科医機能強化型歯科診療所（**か強診**）などは、届出の有無で
日々の算定が変わる。

- `[ ]` 開業時に取得できる施設基準を洗い出す
- `[ ]` 施設基準ごとの**要件**（研修受講、機器の備付、実績年数）を確認
  - 実績要件があるものは開業時に取れない。取得時期を収支計画に反映する
- `[ ]` 各基準の**収益インパクト**を試算し、優先順位をつける
- `[ ]` 2026年度診療報酬改定後の最新要件で再確認（**未確認**）

### 3-2. システム・レセプト

- `[ ]` レセコン／電子カルテの選定（初期費用・保守費・移行性）
- `[ ]` オンライン資格確認、マイナ保険証への対応
- `[ ]` 電子処方箋の対応方針
- `[ ]` レセプト請求の体制（自前 / 外注）と、返戻・査定への対応手順
- `[ ]` 自費診療の価格表、同意書、説明文書

## 4. リスク・その他

### 4-1. 保険とリスク管理

- `[ ]` 歯科医師賠償責任保険（補償額、歯科技工物・インプラントの扱い）
- `[ ]` 火災・什器・機器の保険
- `[ ]` 休業補償、所得補償（院長が倒れたときに借入返済が止まらない）
- `[ ]` サイバー・個人情報漏洩の保険
- `[ ]` 医療事故・クレーム発生時の初動フロー

### 4-2. 集患

- `[ ]` HP・MEO（Googleビジネスプロフィール）— 広告ガイドライン準拠で
- `[ ]` 内覧会の設計と費用
- `[ ]` 近隣医科・歯科との連携、紹介ルート

### 4-3. 事業計画

- `[ ]` 開業スケジュールの逆算表
      （物件契約 → 設計 → 内装着工 → 機器搬入 → 保健所届出 → 保険指定 → 内覧会 → 開院）
- `[ ]` 資金繰り表（開院後、保険診療の入金は**約2ヶ月遅れ**。運転資金の厚みを確認）
- `[ ]` **撤退・立て直しの基準**を先に決める
      （何ヶ月時点で1日何人に届かなければ、何をするか）

## 更新の運用

このチェックリストは、毎週の法令・手続きトラック
（`prompts/regulatory.md`）で見直す。制度改定や要件変更を見つけたら、
該当行を更新し、変更点を `reports/regulatory/` の当日レポートに記録する。
