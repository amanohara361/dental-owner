# 歯科開業前チェックリスト

最終更新: 2026-08-11

財務・立地以外に、開業前に潰しておくべき論点。**法令・許認可 / 人事・労務 /
保険診療の実務 / リスク・その他**の4分野。

数字・期限・要件は制度改定で動く。実際の手続き前に、必ず所管の窓口
（保健所・地方厚生局・労基署・税務署）で最新の要件を確認すること。
本チェックリストは論点の抜け漏れ防止が目的で、法的助言ではない。

凡例: `[ ]` 未着手 / `[~]` 進行中 / `[x]` 完了 / **未確認** = 情報が取れていない項目

## 1. 法令・許認可

### 1-1. 期限のある届出

もっとも事故が起きやすい領域。**保険医療機関の指定**が全体スケジュールの
制約条件になる。

| # | 手続き | 提出先 | 期限の目安 | 状態 |
| --- | --- | --- | --- | --- |
| 1 | 診療所開設届 | 保健所 | 開設後10日以内 | `[ ]` |
| 2 | 保険医療機関指定申請 | 地方厚生局（都道府県事務所） | 月ごとの締切あり／指定日は原則翌月1日 | `[ ]` |
| 3 | エックス線装置備付届 | 保健所 | 備付後10日以内 | `[ ]` |
| 4 | 防火対象物使用開始届 | 消防署 | 使用開始の7日前 | `[ ]` |
| 5 | 個人事業の開業届 | 税務署 | 開業後1ヶ月以内 | `[ ]` |
| 6 | 青色申告承認申請 | 税務署 | 開業後2ヶ月以内 | `[ ]` |
| 7 | 給与支払事務所等の開設届 | 税務署 | 開設後1ヶ月以内 | `[ ]` |
| 8 | 麻薬施用者免許（該当時） | 都道府県 | 使用開始前 | `[ ]` |

**最重要**: 2の保険指定は「内装完成・保健所への開設届済み」が前提。
締切を1日外すと、開院してもその月は**自費診療のみ**になる。
逆算スケジュールの起点をここに置く。

- `[x]` 管轄の地方厚生局事務所の**申請締切日**を確認し、カレンダーに入れる
  → **関東信越厚生局東京事務所の令和8年度分を確認済み**（2026-08-11）。
  申請締切は月ごとに**8日〜10日**と動く（例: 9/10木→10/1指定、10/9金→11/1指定、
  1/8金→2/1指定）。「毎月10日」と覚えると外す月がある。
  **指定日は原則毎月1日付け**。全日程は `reports/regulatory/2026-08-11.md` の1節。
  出典: [東京事務所 締切日一覧（PDF）](https://kouseikyoku.mhlw.go.jp/kantoshinetsu/000477879.pdf)
  ※**締切日は厚生局事務所ごとに異なる。東京以外で開業する場合は管轄事務所で要確認**
- `[ ]` **施設基準の届出**は指定申請とは別カレンダー。**当月1日前後が締切で
  当月1日から算定開始**（例: 令和8年9月1日火 締切 → 9月1日算定開始）。
  指定を取った月から算定するには両方を同月に間に合わせる
- `[ ]` 保健所の**事前相談**（図面段階）を予約する。設計変更を防ぐため内装着工前に

## 2. 人事・労務

### 2-1. 採用

- `[ ]` 必要人員の設計（歯科衛生士・歯科助手・受付・技工の外注可否）
- `[ ]` 地域別の給与相場（歯科衛生士は採用難易度が高く、賃金が上振れしやすい）
- `[ ]` 採用チャネルの選定と費用（求人媒体・人材紹介・専門学校・リファラル）
- `[ ]` **採用は開院の2〜3ヶ月前に開始**。入職後の研修・オペ練習の期間を確保
- `[ ]` 開院前トレーニング（診療の流れ、レセコン操作、電話・受付応対）

### 2-2. 労務の整備

- `[ ]` 雇用契約書・労働条件通知書のひな形
- `[ ]` 就業規則（常時10人以上で作成・届出義務）
- `[ ]` 36協定、勤怠管理の方法
- `[ ]` 社会保険・労働保険の適用関係の確認（開設形態と常時使用者数で変わる）
- `[ ]` 雇用時・定期の健康診断、B型肝炎ワクチン
- `[ ]` 針刺し事故・感染曝露時の対応手順を文書化
- `[ ]` 給与計算の体制（自前 / 社労士 / ソフト）

### 2-3. 外部の専門家

- `[ ]` 税理士（医科歯科に強いか、記帳・決算・保険診療の理解）
- `[ ]` 社会保険労務士（就業規則・助成金）
- `[ ]` 歯科医師会の入会可否 — 会費と、休日当番・研修・紹介の実利を比較

## 3. 保険診療の実務

見落とすと収支計画がそのままずれる領域。

### 3-1. 施設基準の届出

歯科初診料の注1に関する届出（いわゆる**歯初診**）などは、届出の有無で
日々の算定が変わる。

**令和8年度改定後の基本診療料（歯科）の届出項目**（2026-08-11 確認。
[関東信越厚生局 基本診療料の届出一覧](https://kouseikyoku.mhlw.go.jp/kantoshinetsu/shinsei/shido_kansa/shitei_kijun/kihon_shinryo_r08.html)、
ページ更新日 2026-08-03）

| 整理番号 | 名称 | 略称 |
| --- | --- | --- |
| 1-16 | 初診料（歯科）の注1に掲げる基準 | 歯初診 |
| 1-18 / 1-19 | 歯科外来診療医療安全対策加算 1 / 2 | 外安全1 / 2 |
| 1-20〜1-23 | 歯科外来診療感染対策加算 1〜4 | — |
| 1-24 | 歯科診療特別対応連携加算 | 歯特連 |
| 1-25 | 初診料（歯科）の注16及び再診料（歯科）の注13に掲げる基準 | 歯情報通信 |

※かつて記載していた「外来環（歯科外来診療環境体制加算）」は現行の届出一覧に
この名称がない。**「医療安全対策加算」と「感染対策加算」に分かれた体系**になっている。

- `[ ]` 開業時に取得できる施設基準を洗い出す
- `[ ]` 施設基準ごとの**要件**（研修受講、機器の備付、実績年数）を確認
  - 実績要件があるものは開業時に取れない。取得時期を収支計画に反映する
- `[ ]` 各基準の**収益インパクト**を試算し、優先順位をつける
- `[ ]` **か強診（かかりつけ歯科医機能強化型歯科診療所）の現行の位置づけ**（**未確認**）
  - 令和8年度改定の特掲診療料の届出一覧と改定概要【歯科】に名称を確認できなかった。
    廃止か名称変更か確認漏れかは**切り分けられていない。断定しないこと**
  - 特掲診療料の告示本文（保医発0305第8号）で確認する
- `[ ]` **定例報告**（開業後、毎年発生）。基準日は毎年**8月1日現在**、
  令和8年度の提出期限は**令和8年8月31日（月）**。
  ベースアップ評価料を算定する場合は**賃金改善の実績報告・中間報告**が付く。
  出典: [歯科診療所に係る定例報告等について](https://kouseikyoku.mhlw.go.jp/kantoshinetsu/iryo_shido/teirei-shika.html)

## 更新の運用

このチェックリストは、毎週の法令・手続きトラック
（`prompts/regulatory.md`）で見直す。制度改定や要件変更を見つけたら、
該当行を更新し、変更点を `reports/regulatory/` の当日レポートに記録する。
